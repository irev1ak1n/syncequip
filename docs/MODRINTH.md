## Description

Paste the Download, Installation and Commands sections of the README, or this short text:

> SyncEquip turns putting on armor into a coordinated sequence: boots, leggings, chestplate, helmet, shield, a few ticks
> apart, each with its own sound. Squads of any size run the same sequence on one shared server tick, with custom
> loadouts, joining blocks, per-squad speed and group unequip. Server side only, no mods needed.
>
> Install: put the jar in `plugins`, restart. Requires Paper 26.3 and Java 25.
